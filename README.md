# Lead Scout

Веб-приложение для сбора лидов малого и среднего бизнеса по нише и городу.

## Идея (минимум токенов)

Не парсить карточки через LLM. Ниша заранее сопоставлена с тегами OpenStreetMap (`shop=*`, `amenity=*`, …). Поиск идёт через Nominatim (геокод города) + Overpass API. На выходе — таблица: название, телефон, email, сайт, адрес — и CSV.

LLM нужен только если позже захотите расширять словарь ниш из свободного текста; для ядра приложения токены не тратятся.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://127.0.0.1:3847](http://127.0.0.1:3847).

## Как пользоваться

1. Выберите нишу (салоны, кафе, автосервисы, клиники…).
2. Укажите город и радиус поиска.
3. При необходимости оставьте «Только с телефоном».
4. Нажмите «Найти лиды» → экспортируйте CSV.

Режим «Демо-данные» показывает sample-лиды без запроса к OSM.

## Источник данных

- **OpenStreetMap** — открытые данные, покрытие телефонов неполное и зависит от волонтёров.
- Не скрейпит Google Maps / 2ГИС (это нарушает их ToS). Для продакшена тот же UI можно подключить к Places API / официальным API карт как платный слой.
